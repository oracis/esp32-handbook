wifi_hello.ino · Arduino core 3.x
// 连 Wi-Fi + 每 2 秒打印一次 IP 与 RSSI
#include <WiFi.h>

const char* SSID = "your-ssid";
const char* PASSWORD = "your-pass";

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  WiFi.setSleep(false);   // 关省电，延迟更稳
  WiFi.begin(SSID, PASSWORD);
  uint32_t t0 = millis();
  while (WiFi.status() != WL_CONNECTED) {
    delay(300);
    if (millis() - t0 > 15000) {
      Serial.println("wifi timeout, reboot");
      ESP.restart();
    }
  }
  Serial.printf("IP: %s\n", WiFi.localIP().toString().c_str());
}
void loop() {
  Serial.printf("RSSI %d dBm\n", WiFi.RSSI());
  delay(2000);
}

大模型 Agent：这块板子开始自己想了

2026 年最热的一条路。板上只负责听清、说清、执行，理解交给云。两条主线都已成熟：小智 AI 把语音入口和 MCP 控设备做成了标准件，ESP-Claw 干脆把 Agent Runtime 搬进了芯片。

小智 AI · xiaozhi-esp32

33.7K★ · MIT
  • 离线唤醒 ESP-SR 自带中文唤醒词，唤醒不上云，隐私和延迟都省。
  • 链路 Opus 编码 + 流式 ASR → LLM → TTS，WebSocket 或 MQTT+UDP 二选一。
  • MCP 双端 设备端控制音量、灯、舵机、GPIO；云端 MCP 接智能家居、搜索、桌面操作。
  • 硬件 已适配 70+ 开源硬件（S3-BOX3、CoreS3、微雪 AMOLED 等），C3/S3/P4 都能跑。
  • 上手 官方服务器注册就送 Qwen 实时模型额度，烧完固件配网就能说话。

ESP-Claw · espressif/esp-claw

2.4K★ · Apache-2.0
  • 聊天造物 在飞书/QQ/微信/Telegram 里说一句需求，模型生成 Lua 脚本下发到板子执行。
  • 三级路由 Lua 确定性规则走毫秒级；需要理解意图才升级到 LLM；更复杂的转云端模型。
  • MCP 双身份 既能当 Server 把传感器/执行器暴露给别的 Agent，也能当 Client 调外部工具。
  • 记忆本地 结构化记忆存板上（标签 + JSONL），隐私不上云，跨会话还记得你。
  • 门槛 要 Flash ≥ 8MB + PSRAM ≥ 8MB；S3 / P4 / C5 / S31 可用，网页一键烧录。

板上真正能干的，和别指望的

能跑在板上

  • 离线唤醒词（中文自带）、VAD、回声消除（S3/P4 双麦）
  • Opus 编解码 + TLS + WebSocket，8MB PSRAM 够用
  • MCP 工具执行：GPIO、PWM、舵机、WS2812、继电器
  • S3 上的摄像头 JPEG 抓帧、LVGL 表情屏
  • 本地 Lua 规则：断网也能守住的硬约束

别指望

  • 板上跑 7B 级模型 —— 显存单位是 MB，不是 GB
  • 本地 Whisper 级 ASR —— 大模型塞不进 8MB PSRAM
  • 多轮长上下文 —— 40 轮之后必须截断，否则 token 账单失控
  • 高质量端侧 TTS —— 能跑，但一听就是机器
  • 完全离线对话 —— 断网只剩唤醒和本地规则

这六个坑是 AI 硬件专有的

01
麦克风和喇叭装在一个腔体里，一说话就啸叫。 S3/P4 用双麦 + AEC；单麦就物理隔开、做半双工（说话时不开麦）。
02
把 API Key 硬编码进固件。 固件能被 dump，别人刷你的量。走配网页写进 NVS，或干脆自建服务端代理。
03
Wi-Fi 省电模式让音频一顿一顿。 esp_wifi_set_ps(WIFI_PS_NONE)，语音场景别开 modem sleep。
04
在 GPIO35–37 上接麦克风。 S3 的 N16R8 开 Octal PSRAM 会占用这三个脚，接了就不出声。
05
历史对话不清，token 账单失控。 语音输入 80 元/百万 token，按轮数截断上下文，长记忆交给本地摘要。
06
模拟驻极体麦克风直接进 ADC。 底噪大、易被 Wi-Fi 干扰；换 INMP441 这类 I2S 数字麦，一句话解决。
最小 BOM：S3 N16R8 + INMP441 + MAX98357A + 8Ω 2W 喇叭（带腔体），合计 ¥60–140。不想接线的，直接买已适配小智的成品套件（S3-BOX-3、M5Stack CoreS3），开箱带麦、喇叭、屏。见采购清单

先认清型号：11 款芯片，只有 4 种活法

型号不是越高越好。选型的唯一判据是「这台设备必须连上什么」，其次才是算力与 IO。下面按家族分类，最后一列是落地的判断依据。

一句话决策

要屏幕/摄像头/语音 → S3；要 Matter/Thread → C6；只要联网够便宜 → C3；要比 2.4G 更干净的频段 → C5；电池供电压根不要 Wi-Fi → H2；7 寸以上的流畅界面 → P4。

PSRAM 不是标配。型号里的 N16R8 = 16 MB Flash + 8 MB PSRAM，跑 LVGL 大屏和语音必需；买成 N8 就只有 Flash。
P4 没有射频。它是 CPU，不是 SoC，做联网得另配一颗。
型号之外还有 E22 等：乐鑫还有 ESP32-E22（Wi-Fi 6 协处理器）、H21/H4 等衍生型号，多为配套或专用场景，个人开发基本碰不到。看官方 SoC 列表比看淘宝标题可靠。

四条路线：别再问「Arduino 还是 IDF」

真正的问题不是二选一，而是你处在哪个阶段。截至 2026 年 11 月：ESP-IDF 最新稳定版 6.1（2026-08-27 发布）、LTS 分支 5.5.x（补丁 5.5.6）；Arduino-ESP32 core 已到 3.3.x 系列，底层就是 IDF 5.5.5。两者早已不是两个世界。

ESP-IDF 官方 · 正路

C · CMake+Ninja · FreeRTOS
  • 芯片能力全开，OTA / 分区表 / 电源管理原生
  • 组件注册中心按需拉依赖
  • Blink 约 180 KB，比 Arduino 小一个数量级

适合：产品化、低功耗、多协议网关

Arduino core 3.x 最快出东西

C++ · setup/loop · 库最多
  • 半小时点亮，第三方库生态无敌
  • 底层已是 IDF 5.5，性能差距很小
  • 代价：工程化能力弱、每次全量编译

适合：原型、教学、创客项目

PlatformIO 桥

VS Code · framework 一行切
  • 同一份工程，framework 改一行就在 IDF / Arduino 间切换
  • 能直接调 menuconfig，管依赖像 npm
  • 多板多环境并行构建

适合：不想被 IDE 绑架的人

MicroPython / ESPHome 不写 C

Python · YAML
  • REPL 改一行跑一行，验证外设极快
  • ESPHome 用 YAML 描述设备，接 Home Assistant 一把梭
  • 时序敏感场景和极致低功耗都不占优

适合：智能家居、算法验证、不碰编译链

版本这件事，别抄旧教程

网上大量教程基于 IDF 4.x / core 2.x，API 已经变过。IDF 5.2 起官方主推新的 driver/i2c_master.h，旧的 driver/i2c.h 已标记弃用（6.0 起移除）；Arduino core 3.x 则把 ledcSetup/ledcAttachPin 换成了 ledcAttach(pin, freq, res)。看到 #include <driver/i2c.h> 就知道这篇是四年前的了。

查版本的唯一去处是 release-notes.espressif.com 与 github.com/espressif/arduino-esp32/releases。

学习路线

八周路线：每周 6–8 小时，能走完

前提是 C 语言过关。指针和数组不熟的话，先补两周再来 —— 第 3 周就会卡死在那。路线刻意混用两条框架：先用 Arduino 拿反馈，再用 IDF 理解底层。

W1
环境 + 点亮
装 Arduino IDE 2.x 与 core 3.x，跑通 Blink 与串口打印。目标不是「亮灯」，是搞清楚「编译 → 烧录 → 串口」这条链断在哪一环。
W2
GPIO / 中断 / 定时器
按键消抖、外部中断、millis() 非阻塞计时。写一个不阻塞的呼吸灯，理解为什么不该用 delay()。
W3–4
总线：I2C / SPI / UART
接一颗 BME280 读温湿压，再用 SPI 点一块 ST7789 屏。逻辑分析仪（¥30 的克隆版即可）比读十篇文章有用。
W5
Wi-Fi + 一个云端
连 Wi-Fi 打 HTTP GET 拿天气，再推到 MQTT broker。学会处理重连、断网、DNS 失败 —— 这比「连上了」重要得多。
W6
进 ESP-IDF
装 IDF 5.5 LTS，用 idf.py 建工程、menuconfig、分区表。把第 5 周的 Wi-Fi 代码改成 IDF 版，体会事件循环和 FreeRTOS 任务的区别。
W7
FreeRTOS + 双核
两个任务、一个队列。Core 0 跑网络、Core 1 跑采样，用 xTaskCreatePinnedToCore 固定。这是从「能用」到「稳」的分水岭。
W8
OTA + 低功耗 + 收尾
加上 OTA 空中升级（记住要双 app 分区）、深度睡眠唤醒、看门狗。做完这一周，你已经能交付一台真设备了。
之后
选一个垂直方向深挖
LVGL 图形、ESP-ADF 音频、esp-matter 智能家居、ESP-NOW 自组网 —— 四条都能独立成职业方向。

专题深挖：这 5 个方向讲得最细

入门课满地都是，能把一个专题讲到「最后一公里」的很少。下面这五个是筛完之后最接近的 —— 真正的卡点在哪、为什么难，写在描述里了，不是「推荐观看」式的空话。

01
ESP32-CAM：图传与视觉硬件受限 3 条
坑几乎全在硬件，不在代码：OV2640 走 JPEG 直出能到 1600×1200，但 UVGA 以上必须开 PSRAM；帧率是「JPEG 质量 × 分辨率 × Wi-Fi 带宽」三者的共同结果，淘宝页写的 30fps 别当真。先照着做局域网 MJPEG 图传（最短路径，不用服务端），再看那个 10 公里实验 —— 后者不是教程，是协议层极限的实测，看它能建立「物理边界」的直觉。
02
墨水屏：驱动原理与残影物理特性 3 条 + 1 份文档
中文里少有的「自己做驱动」路线：不讲调库，而是从电泳粒子的运动讲到波形，再自己写驱动点亮一块 4.2 寸屏做成阅读器。残影不是 bug，是物理 —— 局刷波形短促，粒子停在中间态，累积到一定程度就擦不掉，只能靠全刷的往复驱动压回两极。通用策略是「局刷 5–10 次插一次全刷，或每小时一次」。
03
ESP-NOW：不用路由器的自组网上手快、难在拓扑 1 条
基于数据链路层的点对点协议，不走 AP、延迟毫秒级、还能和 Wi-Fi / BLE 共存 —— 遥控、传感网、离线配网都靠它。官方这条把协议原理和共存策略讲清了。上手只要两行 API 就能发出一包，真正难的是多节点拓扑、信道管理和掉线后的重建，这部分得自己写。
04
ESP32-P4：HMI 与摄像头官方成体系 6 集
目前中文里唯一成体系的 P4 材料，官方拆成 5 集连载：核心系统（HP+LP 双核）、高清摄像头处理与编码、高清屏显与流畅 HMI、外设与安全、开发平台。做「带大屏的产品」就靠这一套建立整体判断。再强调一次：P4 没有 Wi-Fi 和蓝牙，联网必须外挂 C6 或 C5 当无线协处理器。
05
AI 语音终端：从固件到对话生态最热 1 条 + 上文 09
想理解「AI 硬件」这条链，把官方和社区两面都看一遍最快：官方这条以人脸识别为例，串起 ESP-WHO、语音前端和云端链路，讲的是标准做法；上文卡片 09 的小智 AI 桌宠，则是社区把它做成能摸到的实物。两条对照着看，就知道哪部分是乐鑫给的、哪部分是得自己拼的。

英文视频这条线不进本站。常被推荐的 Andreas Spiess、DroneBot Workshop 都在 YouTube，本机实测 TCP connect 始终无法建立、DNS 还被污染成 157.240.7.20（Facebook 的 IP 段），放上去只会得到一个转圈打不开的链接 —— 与其占位，不如不放，站点保持「点开就一定能看」。需要英文图文的话，资源库里挂了国内可直连的 Random Nerd Tutorials。

别人已经做成了什么（可复刻）

下面 8 个都是完整可查的开源/在售项目，不是「想法」。每个都标了它真正解决的技术难点 —— 那才是复刻时值钱的部分。

CASE 01 · 壁挂式 Home Assistant 控制面板

ESPHome · LVGL · CYD / Guition

2.8″ 或 4.0″ 触摸屏跑磁贴界面，实时反映灯、风扇、窗帘状态，长按弹出亮度滑块。配套 3D 打印外壳，能嵌进标准欧标暗盒。

难点：开机直接进面板而不是桌面（Android 平板做不到这点），以及隐藏走线。屏幕是 ESP32-2432S028（CYD）或 ESP32-4848S040C_I。

CASE 02 · ESP32-P4 点餐机 / Kiosk

ESP-IDF · LVGL · 10.1″ 1024×600

全本地运行：逻辑、菜单、媒体全在 SD 卡里，没有服务器、没有 broker、没有云。触屏点单、播放音视频，源码与 LVGL 模板开源。

难点：P4 没有硬件视频解码跑通用格式，作者用 Python 预转 MJPEG-in-AVI，靠 P4 的算力软解才做到 1024×600 全屏流畅。

CASE 03 · UPI 自动售货机（动态二维码）

ESP32-S3 · 7″ 屏 · 热敏打印

7 寸 CrowPanel 做交互面：选商品 → 按该笔金额生成动态二维码 → 付款成功后驱动热敏打印机出小票。完整的交易终端闭环。

难点：金额与二维码必须一一对应且不可复用，本质是把「支付状态机」跑在 MCU 上，容错比功能重要。

CASE 04 · EKOS 电子墨水看板（众筹在售）

ESP32-S3 · ESP-IDF · ePaper

橡木 + 阳极氧化铝外壳，BME280 测环境，4000 mAh 电池靠 light/deep sleep 调度撑数周。板载 HTTP 服务暴露 OpenAPI 文档化的本地 REST 接口，用 curl 就能改屏。

难点：选 IDF 而非 Arduino 正是为了功耗优化与底层外设控制；界面用 JSON 模板描述、LVGL 渲染，做 1-bit/灰阶优化。

CASE 05 · P4 + 10.1″ 环境监测中枢

ESP32-P4 · LoRa / ESP-NOW · EEZ Studio

六个无线节点位，每个显示名称、电量、信号质量，本地存 24 小时历史曲线。数据不过厂商云，只有天气和 OTA 需要联网。

难点：「过期数据比没数据更误导人」—— 作者把最后上报时间直接摆在卡片上，而不是让屏幕停在几小时前的读数。

CASE 06 · 小智 AI 语音助手

ESP32-S3-N16R8 · 麦克风阵列 · 功放

国内最火的 ESP32 DIY 方向。裸核心板 30 元起，成品盒子 90 元。语音对话 + 表情屏，社区固件已相当成熟。

难点：别买 C3（无 PSRAM 跑不动）；N16R8 的 8 MB PSRAM 是硬门槛；麦克风与喇叭的选型决定了体验的一半。

CASE 07 · 太阳能 / 电费看板

ESP32-P4 · 32 MB PSRAM · 9″ 1024×600

同时显示发电曲线、电池 SOC、分时电价和未来数小时调度计划。站着也能读清 —— 这是 1024×600 的信息密度下限。

难点：多层 LVGL 界面在 400 MHz 双核 + 大 PSRAM 下才不卡；它不是屏幕演示，是本来就必须存在的显示层。

CASE 08 · 经典四件套：气象站 / 时钟 / 相机 / 掌机

ESP32 · ESP32-CAM · TFT_eSPI

BME280 气象站、NTP 网络时钟、ESP32-CAM 图传、8 位模拟器掌机。这四个几乎覆盖了所有基础外设，是被复刻最多的入门项目。

难点：不在功能，在于把它们做「稳」：断网自恢复、内存不泄漏、长时间运行不重启。
复刻不是抄。选一个案例，先跑通它的最小闭环，再换掉其中一个模块（换传感器、换屏、换通信），改动量控制在 30% 以内 —— 这样你既学到了结构，又真的产出了自己的东西。
提醒：先确认目标板子的固件支持的芯片。一个依赖 Arduino 库的 ESPHome 配置在 S3 上能编，在 C6 上会直接失败。

wifi_hello.ino Arduino core 3.x

wifi_hello.ino
// 连 Wi-Fi + 每 2 秒打印一次 IP 与 RSSI
#include <WiFi.h>

const char* SSID     = "your-ssid";
const char* PASSWORD = "your-pass";

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  WiFi.setSleep(false);        // 关省电，延迟更稳
  WiFi.begin(SSID, PASSWORD);

  uint32_t t0 = millis();
  while (WiFi.status() != WL_CONNECTED) {
    delay(300);
    if (millis() - t0 > 15000) {   // 超时就重启，别死等
      Serial.println("wifi timeout, reboot");
      ESP.restart();
    }
  }
  Serial.printf("IP: %s\n", WiFi.localIP().toString().c_str());
}

void loop() {
  Serial.printf("RSSI %d dBm\n", WiFi.RSSI());
  delay(2000);
}

espnow_pair.c ESP-NOW 点对点，无需路由器

espnow_pair.c
// 发送端：上电广播一条结构体
#include "esp_now.h"
#include "esp_wifi.h"

typedef struct { float temp; uint16_t seq; } pkt_t;
static const uint8_t PEER[6] = {0xFF,0xFF,0xFF,0xFF,0xFF,0xFF};

void app_main(void) {
  nvs_flash_init();
  esp_netif_init();
  esp_event_loop_create_default();
  esp_wifi_init(&wifi_init_cfg);
  esp_wifi_set_mode(WIFI_MODE_STA);
  esp_wifi_start();

  esp_now_init();
  esp_now_peer_info_t p = { .channel = 1, .encrypt = false };
  memcpy(p.peer_addr, PEER, 6);
  esp_now_add_peer(&p);            // 广播地址要显式加 peer

  pkt_t d = { .temp = 23.4f, .seq = 0 };
  for (;;) {
    esp_now_send(PEER, (uint8_t*)&d, sizeof d);
    d.seq++; vTaskDelay(pdMS_TO_TICKS(1000));
  }
}

deep_sleep.ino 定时唤醒，10 µA 级待机

deep_sleep.ino
// 采样 → 上报 → 睡 60 秒 → 循环
#define BUTTON_PIN 0

void setup() {
  Serial.begin(115200);
  delay(100);
  Serial.println("wake up");

  // 这里做一次采样 + 联网上报，尽量在 2 秒内完成

  // 关键：把所有不用的外设彻底断电/隔离，否则漏电流会吃掉收益
  gpio_hold_en((gpio_num_t)BUTTON_PIN);
  esp_sleep_enable_ext0_wakeup((gpio_num_t)BUTTON_PIN, 0);
  esp_sleep_enable_timer_wakeup(60ULL * 1000000);
  esp_deep_sleep_start();   // 不会再返回 loop()
}

void loop() {}

踩坑清单

踩坑清单：这十条能省你两个周末

都是「现象 → 原因」的形式，方便你按症状反查。

01
烧完串口全是乱码。 波特率不对（日志默认 115200），或者供电不足导致芯片反复复位。换根能传数据的 USB 线，别用只能充电的。
02
一直停在 "Connecting..."。 手动按住 BOOT 再点 RESET 进下载模式；驱动没装（CH340 / CP210x / CH343 各不相同）也会这样。
03
GPIO 6–11 用了就死机。 这几根接着内部 SPI Flash，初代 ESP32 上绝对不能用。选引脚前先查对应型号的引脚表。
04
ADC 一开 Wi-Fi 读数就飘。 初代 ESP32 的 ADC2 与 Wi-Fi 共用硬件，联网时不可用。要测模拟量就用 ADC1（GPIO32–39）。
05
5V 接到了 3.3V 引脚。 当场烧。板子上有 5V/VIN 和 3V3 两个丝印，接线前看两遍。烧了别急着扔，多数是稳压器，能换。
06
OTA 一直失败。 默认分区表只有一个 app 分区，放不下第二份固件。要在 menuconfig 里改成 "Factory app, two OTA definitions"。
07
S3 买了 8MB PSRAM 却只剩一点。 8MB 是 octal 模式，必须显式开启（ESPHome 里 psram: mode: octal，IDF 里改 sdkconfig），否则默认不启用。
08
Wi-Fi 隔一会儿就断。 默认开了 modem sleep。要长连接就 WiFi.setSleep(false)，代价是功耗上升。另外关掉路由器里的「节能/802.11 省电」试试。
09
信号差、距离短。 板载 PCB 天线怕金属和手。装进金属盒必须换外置天线（IPEX/U.FL），并且天线净空区不能铺铜。
10
深度睡眠还是耗电几十 mA。 睡眠前没把外设断电、没做引脚 hold，传感器和 LDO 继续吃电。要逐项隔离测量，别信数据手册的 typ 值。

术语速查

术语速查

看文档时被这些缩写卡住的话，回来查一眼。

SoC / 模组 / 开发板
芯片本体 / 芯片+晶振+天线+屏蔽罩 / 模组+USB+稳压+排针。买「开发板」最省事，做产品用「模组」。
PSRAM
片外伪静态内存。跑 LVGL、摄像头帧缓冲、语音缓冲必需。型号里 R8 就是 8MB。
NVS
非易失存储，类似小 KV 数据库。存 Wi-Fi 密码、校准值、设备配置。
OTA
空中升级。需要双 app 分区 + 回滚标记，别只做「能刷进去」。
Matter / Thread
跨品牌智能家居应用层 / 低功耗网状网络层。C6 是单芯片同时支持的那颗。
ESP-NOW
乐鑫私有 2.4G 点对点协议，不需要路由器，延迟毫秒级，适合遥控与传感网。
RMT
红外/WS2812 用的精确脉冲外设。驱动灯带比软件延时可靠得多。
I2S
数字音频总线。麦克风、功放、DAC 都走它。做语音项目第一个要搞懂的。
TWAI
ESP-IDF 里的 CAN 总线驱动名。车上/工业场景用。
eFuse
一次性熔断位。安全启动、Flash 加密、MAC 都存在这，熔了不可逆。
看门狗 (TWDT)
任务超时未喂狗就复位。长循环里记得 vTaskDelay 或喂狗。
menuconfig
IDF 的图形化配置树，产出 sdkconfig。串口、分区表、组件开关都在这。
