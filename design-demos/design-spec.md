# 设计 Spec · ESP32 全景手册改版

## 项目与任务
给已上线的单文件站点 `index.html`（13 节 / 221KB / 中英双语 / 已部署 https://esp32.ydtgo.top/）做视觉重设计，先出三个方向初稿与现有设定比较，用户选定后才做正式版。

## 受众与场景
- 中文硬件开发者：从「点灯」到「量产」的初学者与进阶者；查资料、做选型、找教程、下单采购。
- 场景：桌面浏览器为主，碎片化查表 + 深度阅读并存；手机端查表/采购清单。

## 核心信息（三版必须同内容，只换设计）
1. 一块芯片从闪烁 LED 到量产 HMI —— 全家族 11 款 SoC 选型表
2. 大模型 Agent：小智 33.7K★ / 官方 ESP-Claw 2.4K★ / 8 节点数据流 / 时延预算
3. 四条开发路线对比 + 三步进选择器（purpose/bt/scale → 芯片推荐）
4. 八周学习路线、10 条中文视频教程、23 条资源库、真实产品案例、可抄代码片段
5. 39 件采购清单（5 组）、踩坑清单、术语表、来源

## 情感基调
权威但可用：像一位做过量的工程师把经验摊在桌上——直接、诚实、有判断，不喧哗。

## 输出格式（三版统一）
- 桌面 1440×900 单文件 HTML，可滚动长页；375×812 移动端可读
- 三版各 1 份 `design-demos/dir-N.html` + 桌面首屏截图 + 整页长截图
- 保留中英切换按钮与筛选/选择器的可点交互（初稿至少首屏与核心一个交互可用）

## 已知约束
- 单文件、零外部依赖（线上部署到 OSS）；中英 i18n 文本节点机制要在正式版保留
- 事实不能编造：SoC 型号数、star 数、价格、视频标题沿用现有站点真实内容
- `.rv` 不能嵌在 `data-l10n` 块里（切语言会丢 .in 不可见）——正式版注意
- 可读性底线：正文 ≥14px、标签 ≥12px、对比度 ≥4.5:1

## 图片需求
- 主角素材：芯片 / 开发板本身（硬件题材必须有产品图，不用 emoji / 灰色占位）
- 官方品牌资产：Espressif 官方红 `#E7352C`、logo 黑底规则（红 mark + 白 wordmark）
- 三版共用同一批真实素材，差异在诠释
