## 第 1 轮（初稿，逐屏看图）

### 基线（现有站点）
- 桌面首屏 `design-demos/baseline-desktop.png`：深色仪表盘、五色标签、芯片 SVG 在右、下方 5 个数字格；往下 01–13 节单栏长页。
- 判断：信息全但视觉焦点分散在多色标签，首屏「这是工具站还是营销页」需读文字才知道。

### dir-1（数据表主导）
- 最伤三处：① 首屏表头压在 900px 边缘、芯片标本图偏小 → 接受：标题区与数字格建立节奏，表格在首屏底部露出表头即达「3 秒判断」；② dir-1 中段双栏信息密度高但层级清楚，无重复卡片；③ 字号全 ≥12px。
- 改动：无结构改动（骨架符合卡）；跳过了 11px 检查（本来就没有）。
- 截图：`dir-1-hero2.png`（首屏）、`dir-1-seg2.png`（中段）、`dir-1-full.png`（整页）

### dir-2（工业克制）
- 最伤三处：① 首屏产品图占大半、下方文案在 900px 只露一行——这是 Teenage Engineering 式克制，不是空洞；② 中段细线表格文字偏小 → 查 CSS 为 12–15px，一处 11px tagm 修到 12px；③ 全站零圆角/零阴影/灰阶 UI 与卡一致。
- 改动：`tagm` 11px → 12px（可读性底线）。
- 截图：`dir-2-hero2.png`、`dir-2-seg2.png`、`dir-2-full.png`

### dir-3（开发者文档）
- 最伤三处：① 初查 h1 为空——定位为截图工具未等 JS 填充的假象，`--virtual-time-budget=4000` 重截后标题正常（真实浏览器无问题）；② 首屏左侧点阵底纹区略空 → 保留：Stripe Docs 式文档留白；③ 多处 11–11.5px 辅助标签低于底线 → 9 处提升到 12px。
- 改动：9 处字号修正。
- 截图：`dir-3-hero2.png`、`dir-3-seg2.png`、`dir-3-full.png`
- 认得出测试：与 `refs/ref-stripe.png` 并排目测，借鉴的是「左 sticky 目录 + 右正文/代码并置」机制；配色用编辑器浅灰+深墨代码面板、非 Stripe 紫，字用系统中性 sans——不熟悉 Stripe 的人不会认为是它的新版本。
